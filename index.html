bazixv13 Apps

One remote for Hideaway and the rest of your apps.

Add the remote

flatpak remote-add --if-not-exists --from bazixv13-apps https://bazixv13.github.io/flatpak-repo/flatpakrepo

Install an app

Open one of these with GNOME Software or Bazaar, or download it and run flatpak install on it — it adds the remote and the key for you.

  • Hideaway — install
  • LocalSend (stable) — install
  • LocalSend (beta) — install
flatpak install bazixv13-apps io.github.bazixv13.Hideaway

What's available

  • Hideaway — io.github.bazixv13.Hideaway (branch master)
  • LocalSend — io.github.localsend_adwaita.LocalSend (branches stable, beta)

Full list: flatpak remote-ls bazixv13-apps
